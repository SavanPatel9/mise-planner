# Mise

**Everything in its place before your day begins.**

Mise (from _mise en place_) is a personal task manager that turns a messy
morning brain-dump into a realistic day: Claude parses free text into structured
tasks, the planner fits them into the free blocks of your Google Calendar, you
work through them in multi-task Pomodoro sessions that double as automatic
time-tracking, and an end-of-day summary shows planned vs. actual.

Full spec: [docs/spec.md](docs/spec.md) · Build plan: [docs/plan.md](docs/plan.md)

## Stack

TypeScript · React + Vite + Tailwind (`apps/web`) · Express (`apps/api`) ·
Postgres + Prisma · Claude API · Vercel + Neon
